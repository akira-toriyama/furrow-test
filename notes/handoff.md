# 次回への申し送り（A4 一枚）

`wrap-handoff-sheet` が書く。各項目に「次回そのまま使う」「次回変える」を必ず付ける。金額は実績値で書く。
1 枚に収まらない分は捨てる。次回の task 群はこの 1 枚から手で起こす。

| 見出し | 項目 | 実績 | 次回 |
|---|---|---|---|
| 会場 |  |  | そのまま / 変える |
| 献立 |  |  | そのまま / 変える |
| 予算 |  |  | そのまま / 変える |
| 当日運営 |  |  | そのまま / 変える |
| 撤収 |  |  | そのまま / 変える |

## 入口

- `wrap-next-decision`（次回開催の要否判定）
- `wrap-handoff-refresh`（1 年後の読み直し）
