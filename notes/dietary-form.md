設問文の正本は `menu-intake-questions`。このファイルは配布するフォームの文面と、回収した申告表を置く場所。
回答期限: 2026-10-10（開催日の D-42）。未回答者は甲殻類アレルギーあり前提で設計する（特定 8 品目は設問で聞くが、回避設計は甲殻類だけに絞る）。残りは当日の口頭確認に回す。

## 設問（5 問）

1. 次のうち食べられないものを選んでください（選択式・複数可）: えび / かに / くるみ / 小麦 / そば / 卵 / 乳 / 落花生 / なし
2. 1 で選んだものについて、重症度を教えてください（接触で症状 / 加熱蒸気で症状 / 微量混入で症状 / 量が少なければ可）。エピペンを携行していればその旨も。
3. 苦手で避けたいもの（自由記述。「食べられない」とは別に扱います）
4. 肉・魚の可否（両方可 / 魚のみ / 肉のみ / どちらも不可・ベジタリアン / ヴィーガン）。ベジタリアン・ヴィーガンの方は出汁（かつお・煮干し）の可否も。
5. 飲めないお酒があれば教えてください（自由記述）。「制限なし」も明示回答として記録します。

未回答のまま期限を過ぎた方には、甲殻類を使わない皿をお出しします。その他の品目は当日その場で伺います。
